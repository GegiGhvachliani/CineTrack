SharedNetworking - დოკუმენტაცია

აქ აღწერილია SharedNetworking საქაღალდეში (Folder) არსებული თითოეული ფაილის დანიშნულება და პასუხისმგებლობა. ეს არქიტექტურა უზრუნველყოფს სუფთა, ტესტირებად და მარტივად გასაფართოებელ ქსელურ ფენას.

1. APIClient.swift
ტიპი: კლასი ან აქტორი (Class / Actor)
პასუხისმგებლობა: წარმოადგენს ქსელური ფენის მთავარ "ძრავს". ის უშუალოდ უკავშირდება სერვერს (ძირითადად URLSession-ის გამოყენებით).
მისი მთავარი ფუნქციაა მიიღოს შექმნილი APIRequest, გააგზავნოს ქსელში მოთხოვნა, დაელოდოს სერვერის პასუხს, დააპარსოს (Decode) მიღებული JSON მონაცემები ლოკალურ მოდელებში და დააბრუნოს საბოლოო შედეგი ან შეცდომა (NetworkError).

2. HTTPMethod.swift
ტიპი: ჩამონათვალი (Enum)
პასუხისმგებლობა: განსაზღვრავს სტანდარტულ HTTP მეთოდებს (მაგალითად: GET, POST, PUT, DELETE, PATCH).
მისი მიზანია კოდის ტიპიზებული უსაფრთხოების (Type Safety) უზრუნველყოფა. ამის გამოყენებით თავიდან ვირიდებთ შეცდომებს, რომლებიც შეიძლება გამოწვეული იყოს მოთხოვნის მეთოდის ტექსტურად (String) ხელით წერისას (მაგ. შემთხვევით "POST"-ის ნაცვლად "POS"-ის დაწერა).

3. APIRequest.swift
ტიპი: პროტოკოლი (Protocol) ან სტრუქტურა (Struct)
პასუხისმგებლობა: წარმოადგენს ნებისმიერი კონკრეტული API მოთხოვნის (Endpoint-ის) შაბლონს.
თითოეული ენდფოინთი (მაგ. ლოგინი, იუზერის წამოღება) შეესაბამება ამ პროტოკოლს. ის თავის თავში ინახავს მოთხოვნის გასაგზავნად საჭირო ყველა ინფორმაციას:
- Path (ბმულის ბოლო ნაწილი, მაგ. "/api/v1/login")
- HTTPMethod (GET, POST...)
- Headers (ჰედერები, მაგ. Authorization token)
- Parameters/QueryItems (პარამეტრები URL-სთვის)
- Body (ტანი, POST მოთხოვნებისთვის)

4. NetworkError.swift
ტიპი: ჩამონათვალი (Enum, რომელიც აკმაყოფილებს Error პროტოკოლს)
პასუხისმგებლობა: აერთიანებს ქსელური ოპერაციების დროს წარმოქმნილ ყველა შესაძლო სპეციფიკურ შეცდომას.
მაგალითად: .invalidURL, .noInternetConnection, .decodingFailed, .unauthorized, .serverError(statusCode: Int). მისი მიზანია შეცდომების მართვის (Error Handling) გამარტივება, რათა UI-ს ან ViewModel-ს ზუსტად ვაცნობოთ რა წავიდა არასწორად და მომხმარებელს შესაბამისი მესიჯი ვაჩვენოთ.

HTTPMethod      → რა ოპერაციას ვაკეთებთ
APIRequest      → რა უნდა გაიგზავნოს
APIClient       → რა კონტრაქტით იგზავნება
URLSessionAPIClient → რეალური გამგზავნი
NetworkError    → რა ტიპის შეცდომა მოხდა
