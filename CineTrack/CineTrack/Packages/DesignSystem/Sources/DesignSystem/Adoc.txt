DesignSystem (ვიზუალური საძირკველი)
რა არის ეს?
DesignSystem არის შენი აპლიკაციის "სახე" და ვიზუალური იდენტობა. აქ იყრის თავს ყველა ის UI ელემენტი და წესი, რომელიც უზრუნველყოფს, რომ აპლიკაციის ყველა ეკრანი ერთნაირად ლამაზად და სტანდარტულად გამოიყურებოდეს.

მთავარი წესი:
DesignSystem-ში არასდროს ვწერთ ბიზნეს ლოგიკას. ამ პაკეტმა არ იცის რა არის ინტერნეტი, TMDB ან CoreData. ის იღებს ტექსტს/სურათს და უბრალოდ ხატავს მას ეკრანზე.



რა უნდა ჩადო შიგნით (კონკრეტული მაგალითები შენი პროექტისთვის):

დიზაინ ტოკენები (Design Tokens):

Colors.swift - აპლიკაციის ფერების პალიტრა. კოდში აღარ დაწერ .red ან .black. დაწერ: DesignSystem.Colors.primaryBackground ან DesignSystem.Colors.accentGold.

Typography.swift - ფონტების სისტემა. (მაგ. heading1, bodyText, caption).

Spacing.swift - დაშორებების სტანდარტი (მაგ. .small = 8pt, .medium = 16pt, .large = 24pt).



საერთო მცირე კომპონენტები (Atoms / UI Components):

CTButton.swift - CineTrack-ის მთავარი ღილაკი. როცა ონბორდინგში ან ლოგინში ღილაკი დაგჭირდება, ამას გამოიძახებ.

CTTextField.swift - ტექსტის შესაყვანი ველი თავისი დიზაინით, ერორის მდგომარეობით და ა.შ.

LoadingSpinner.swift - ერთიანი დიზაინის მქონე ლოუდერი.



რთული საერთო კომპონენტები (Molecules):

MovieCardView.swift - ფილმის პატარა ბარათი (პოსტერით და რეიტინგით), რომელსაც გამოიყენებ როგორც Home ფექიჯში (Trending სიაში), ასევე Search და Watchlist ფექიჯებში.

RatingBadgeView.swift - პატარა ყვითელი ვარსკვლავი და ციფრი (მაგ. ⭐️ 8.5), რომელიც სხვადასხვა ადგილას მეორდება.







💡 "შემამოწმებელი კითხვები" (Cheat Sheet) გადაწყვეტილების მისაღებად
როცა დაფიქრდები, "ეს ფაილი სად წავიღო?", დაუსვი შენს თავს ეს კითხვები:

კითხვა 1: ეს ფაილი ინტერნეტიდან იწერს რამეს? ბაზაში ინახავს? რაიმე რთულ კალკულაციას აკეთებს?
👉 პასუხი: კი? მაშინ მისი ადგილი SharedKit-შია.

კითხვა 2: ეს ფაილი ეკრანზე რამეს ხატავს (View, Button, Color)? აქვს import SwiftUI ან import UIKit მთავარ როლში?
👉 პასუხი: კი? მაშინ მისი ადგილი DesignSystem-შია.

კითხვა 3: ეს ფაილი კონკრეტულად პროფილის ეკრანის ლოგიკაა (მაგ. ProfileViewModel)?
👉 პასუხი: მაშინ მისი ადგილი არცერთში არ არის. ეგ პირდაპირ Profile Feature ფექიჯში უნდა ჩადო.
